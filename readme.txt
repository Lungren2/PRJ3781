This is version v0.1 of the Job Crawler and does not yet communicate with the API/DB and the format of the output is not dinalized.

The idea is that the Job crawler takes not of all the particulars of the job requirements and details to match up with users' CV's and preferences later on.
It is also so that we can display this information on the websites when users are browsing job entries.

The code has comments throughout the relavant files so that you can understand what it does.
